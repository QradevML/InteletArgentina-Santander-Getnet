# Tarjetas digitales de InteletGroup SRL

Proyecto preparado para publicar con **GitHub Pages**. Cada colaborador tiene su propia carpeta con un `index.html`, lo que permite generar un QR individual por persona.

## Estructura
- `index.html`: galería general del equipo.
- `nombre-apellido/index.html`: tarjeta individual del colaborador.
- `assets/css/style.css`: estilos compartidos.
- `assets/fotos/`: fotografías optimizadas en WebP.
- `assets/logos/santander-argentina.png`: logo utilizado en las tarjetas.

## Publicación con GitHub Pages
1. Crea un repositorio público.
2. Sube **el contenido de esta carpeta** (no el ZIP) a la raíz del repositorio.
3. En GitHub, ve a `Settings > Pages`.
4. En `Build and deployment`, selecciona `Deploy from a branch`.
5. Elige la rama `main` y la carpeta `/(root)`.
6. Guarda los cambios y espera la URL pública.
